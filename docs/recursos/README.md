# Recursos — los archivos que mandan

Aquí van los archivos originales que definen cómo debe ser el producto (hojas de cálculo, tablas de
roles, formatos). Cada uno tiene **su página en Markdown** al lado, con la transcripción, para que se
pueda buscar en el repositorio y lo lean las personas y los agentes de IA.

**Regla:** lo que dice un recurso es obligatorio para todos los repositorios de IDIKY. Si un cambio lo
contradice, se le pregunta a su dueño **antes** de construir.
